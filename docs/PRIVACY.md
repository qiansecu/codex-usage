# 数据、连接和本地文件

## 读取内容

- 按当前聊天ID定位所指定会话目录中的记录，以只读方式解析token、模型、轮次及耗时事件。读取器会读取记录文件，文件本身可能含聊天正文，不能把它当成可随意分享的普通日志。
- 从客户端DOM读取会话/轮次标识、布局和原生样式。
- 通过已有客户端桥接读取账号额度、当前聊天工作区元数据；点击工作区按钮时调用原生文件管理器。

不要求输入或复制API Key、不读取凭据文件，不修改客户端安装包或签名。本工具没有外部统计上报功能；正常客户端自身的网络行为不受本工具控制。

## 调试连接

启动时只允许调试端口监听 `127.0.0.1`，并核对它属于本次已注册安装包进程。页面发现使用本机HTTP，控制使用本机WebSocket。不是加密远程服务，不能把监听地址改成公开网卡地址。

CDP能够控制客户端页面，拥有本机访问能力的程序可能接触该端口。撤销统计运行并普通启动后即可不再以这次调试方式运行。

## 写入内容

成功启动后app/settings.local.json仅记录Node、Python和会话目录三个本地路径，供快捷方式沿用；不复制官方配置或凭据。该文件属于个人信息，已被Git忽略。

额度卡可见性是唯一新增的界面偏好，保存在客户端origin的localStorage键 `codex-usage-ui:quota-visible:v1`，值仅0/1，不包含账号、会话或凭据。

`app/runtime-installed/` 含进程/端口身份、连接日志、会话/轮次ID、统计数值、模型名、耗时及工作区路径等；`launcher/state/` 保存快捷方式路径、哈希和原链接备份，`launcher/last-launch.log`保存启动输出。测试还会在被忽略目录创建合成样本。

这些文件均不应提交Git或附在公开Issue中。即使没有聊天正文，路径、模型名、用量和ID仍可能暴露私有信息。分享时只提供必要、已去除私有信息的片段。

## 发布检查

仓库 `.gitignore` 排除运行目录、用户配置、会话记录、日志、恢复备份和生成二进制。`scripts/check-public.mjs`检查待公开文件的路径、个人绝对路径和常见密钥模式，但不是完整的泄密审计。维护者仍须审阅Git文件清单和改动。

如果私有文件已提交，添加ignore并不能清除Git历史。先阻止继续发布，根据实际泄露范围处理凭据与仓库历史，不能仅删除工作区文件后宣称问题消失。
