# Codex Meter

在Windows桌面客户端中显示单轮token、会话统计、缓存命中、上下文占用和账号剩余额度。个人维护的非官方工具，与OpenAI无隶属关系；通过本机CDP加载界面，不修改安装包、签名或登录配置。

## 快速开始

需要Windows、PowerShell 7、Node.js 22+、Python 3.10+，以及已安装并登录的Microsoft Store `OpenAI.Codex`客户端（界面名称可能显示为ChatGPT）。没有npm/pip第三方依赖。

1. 将完整项目下载到准备长期保留、当前用户可写的目录。
2. 保存工作并完整退出普通客户端，再双击最外层 **start.cmd**。
3. 脚本生成所需界面载荷，启动安装版并核对本次注入成功后，自动在 **桌面和开始菜单各创建一个“ChatGPT（统计）”入口**。
4. 以后从新入口启动即可。原客户端快捷方式不会被替换，不设置开机自启；固定到开始菜单/任务栏可由用户自行操作。

启动器优先本地编译静默EXE，编译器不可用时快捷方式直接指向PowerShell 7和本项目注入脚本。发现同名未知入口或用户修改时会保留并提示。首次启动的解释器/会话路径只保存在被Git忽略的本工具本地设置中。

也可让AI阅读 [AI安装说明](docs/AI_INSTALL.md) 来安装，或先看 [详细安装步骤](docs/INSTALL.md)。

项目仓库：[qiansecu/codex-usage](https://github.com/qiansecu/codex-usage)。下载源码时请保留完整目录结构。

## 功能

- 回复时间旁显示“用量 … tok”，随原生时间悬停显示，点击查看本轮模型和token明细。
- 输入框下方显示轮次/步数、输出速度、总量/缓存命中、上下文百分比，三个模块可打开详情。
- 左下角76px紧凑额度卡显示5小时/1周剩余，低于10%变红；头像上方开关控制显示并记住选择。卡片只展示，头像保留原生菜单。
- 标题栏文件夹按钮打开当前聊天的本地工作区。
- 跟随聊天切换，无法匹配或数据过期时隐藏或显示“—”，不会借用其他聊天的数字。

累计用量可能包括继承，缓存读取已包含在输入中。TPS、模型活动和上下文为基于本地事件的估算；账号额度另来自原生接口，不能与token相互换算。没有本地记录的聊天可能没有token统计。

## 重载与移除

| 操作 | 入口 |
| --- | --- |
| 仅重载统计，保留客户端 | app/reload-statistics.cmd |
| 撤销本次统计并关闭调试客户端 | app/restore-installed.cmd，先保存工作 |
| 移除统计入口/恢复同名入口备份 | launcher/restore-shortcuts.cmd，不关闭当前窗口 |
| 检查源码与计算逻辑 | app/check-local.cmd，不启动客户端或操作真实快捷方式 |

卸载前先撤销本次运行、恢复统计快捷方式，再删除工具目录；不删除官方配置或会话。建立入口后不要直接移动目录。

## 兼容与验证范围

目标是Windows的上述注册安装包，不支持macOS、Linux或网页版。客户端更新可能改变DOM、资源模块或记录格式，需要重新适配。

| 客户端版本 | 实际验证范围 |
| --- | --- |
| 26.1007.9446.0 | 原维护环境中验证过单轮、摘要、四种详情、额度与工作区按钮 |
| 26.1013.4894.0 | 额度卡、开关和头像菜单经用户确认；工作区接口就绪，实际点击未复验 |

公开版安装/自动快捷方式使用合成目录测试，尚未在第二台电脑完成首次安装验收。CI不登录或操作桌面客户端。测试通过不等于所有后续客户端版本都兼容。
